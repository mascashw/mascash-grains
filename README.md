# MASCASH Grains

**Buying and selling grains**

MASCASH is a grain buying and selling website built with Next.js, TypeScript, Tailwind CSS, Prisma, and PostgreSQL.

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL

## Deployment

The website can be deployed using [Vercel](https://vercel.com/). Configure the required environment variables and connect a production PostgreSQL database before deployment.
